# Carbon Storage in Orange Trees in LCA

In an LCA for oranges, carbon storage in trees should be accounted for as a temporary carbon sink, but handled carefully. Since orange trees typically live 50-80 years, they represent medium-term carbon storage rather than permanent sequestration.

The recommended approach is to:

1. Include biogenic carbon uptake during tree growth as a negative emission
2. Account for carbon release when trees are removed/die as a positive emission
3. Apply time-dependent characterization factors if the study timeframe is relevant to climate change impacts

The rationale is that while orange trees do sequester carbon in biomass, this storage is temporary. Following ISO 14067 and PAS 2050 guidelines, temporary storage should be acknowledged but distinguished from permanent sequestration.

For attributional LCAs, report biogenic carbon flows separately from fossil emissions. For consequential LCAs, consider land use change impacts if orange production expands into new areas.

This balanced approach avoids overstating climate benefits while still recognizing the temporary carbon storage function of orange orchards within the agricultural system.
