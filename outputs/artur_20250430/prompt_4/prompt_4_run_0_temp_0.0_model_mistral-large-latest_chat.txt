Explanation: According to the ISO 14044 standard, an ISO-compliant Life Cycle Assessment (LCA) study must specify key requirements such as the functional unit of the reference flow, allocation procedures, and the type of critical review, if any. However, the addresses of upstream suppliers are not a mandatory requirement to be specified in the LCA study. The focus is on the methodological aspects and the scope of the assessment rather than specific supplier details.
