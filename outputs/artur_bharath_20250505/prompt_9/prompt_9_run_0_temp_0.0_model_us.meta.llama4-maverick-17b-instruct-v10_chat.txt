To systematically compare the two LCAs and resolve the discrepancy, I propose the following analytical framework:

1. **Methodological comparison**: Examine the data sources, system boundaries, functional units, and Life Cycle Impact Assessment (LCIA) methods employed in both studies. Differences in these aspects can significantly influence the results (Reap et al., 2008). For instance, variations in data sources (e.g., primary vs. secondary data) can lead to disparate conclusions. Similarly, differences in system boundaries (e.g., cradle-to-gate vs. cradle-to-grave) can affect the scope of the assessment.

2. **Harmonization**: To compare the studies on a level playing field, harmonize the LCAs by adjusting the parameters to match (Schreiber et al., 2019). This involves:
	* Aligning the functional units (e.g., kg of protein or serving size) to ensure a consistent basis for comparison.
	* Normalizing the LCIA methods to a common framework (e.g., ReCiPe or IMPACT 2002+).
	* Adjusting the system boundaries to match, if possible.

3. **Sensitivity analysis**: Perform a sensitivity analysis to identify the key drivers of the discrepancies (Groen et al., 2017). This involves analyzing how changes in input parameters or methodological choices affect the results.

4. **Reliability assessment**: Evaluate the reliability of each study based on factors such as data quality, transparency, and peer-review status. A study with high-quality, primary data and transparent methodology is likely more reliable (Weidema et al., 2013).

5. **Recommendations for future LCAs**: To avoid similar discrepancies, future LCAs should:
	* Clearly document data sources, system boundaries, and LCIA methods.
	* Use consistent functional units and system boundaries.
	* Perform sensitivity analyses to test the robustness of the results.
	* Consider using harmonized LCIA methods to facilitate comparisons (e.g., Mendoza Beltran et al., 2016).

By following this framework, it is possible to systematically compare the two LCAs, identify the sources of the discrepancy, and determine which conclusions are more reliable. Future LCAs can benefit from these recommendations to improve their comparability and reliability.
