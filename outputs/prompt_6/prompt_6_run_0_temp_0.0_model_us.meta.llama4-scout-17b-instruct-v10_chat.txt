The functional unit of a product system in life cycle assessment (LCA) is a quantified description of the product's function, serving as a reference unit for the analysis. It defines the basis for comparison and ensures that the assessment is performed on an equivalent basis. For example, for a disposable and a reusable product, the functional unit might be "one washed meal plate." This allows for an apples-to-apples comparison of environmental impacts. The functional unit is a key element in LCA, enabling meaningful comparisons between different product systems. It is usually expressed in terms of a specific service provided.
