### Understanding the Hierarchy of Allocation

In LCA, when a system produces more than one product (multi-functionality), it is necessary to **allocate the environmental impacts** among the products. The ISO standards, including **ISO 14044** and **ISO 15804**, emphasize a **hierarchical approach** to this allocation:

1. **Avoid allocation** by **modifying the system boundary** (e.g., by expanding or subdividing the system to eliminate the need for allocation).
2. If allocation is unavoidable, use **allocation based on physical properties** (e.g., mass, energy, or volume), which is more objective and scientifically grounded.
3. As a **last resort**, use **allocation based on revenue**, which is more subjective and less preferred due to its dependence on market values.
