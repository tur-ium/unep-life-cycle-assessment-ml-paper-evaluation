**Correct Answer:**  
**A: 1. Avoid allocation as far as possible, 2. Allocation on basis of physical properties, 3. Allocation on basis of revenue**

### Explanation:
1. **Avoid allocation** (preferred): Modify the system boundary through subdivision or expansion to eliminate the need for allocation entirely.  
2. **Physical allocation** (second): If avoidance is impossible, allocate based on measurable physical relationships (e.g., mass, energy).  
3. **Economic allocation** (last resort): Use revenue or market value as a basis only when physical allocation is not feasible.  

This hierarchy minimizes subjectivity and ensures consistency with broader LCA standards like ISO 14044.
